\begin{abstract}
As enterprise network perimeters transition toward decentralized edge topologies, conventional centralized Network Intrusion Detection Systems (NIDS) incur substantial bandwidth overhead and privacy violations by aggregating raw flow telemetry. While Federated Learning (FL) mitigates privacy leakage, Non-IID network partitions, high-rate malicious poisoning attacks, and latency bottlenecks hinder practical deployment. In this work, we propose \textbf{Fed-GNIDS}, a dual-engine federated graph intrusion framework. Fed-GNIDS combines a Graph Attention Network v2 (GATv2) spatial topology encoder with a Gated Recurrent Unit (GRU) temporal aggregator to model sequential multi-hop network interactions without leaking flow payloads. To counter Byzantine adversarial poisoning, the federated orchestrator enforces Adaptive Cosine Similarity (ACS) gradient aggregation under Local Differential Privacy (LDP). Evaluated across 24,000 temporal flow instances from the authentic UNSW-NB15 benchmark, our calibrated dual-engine framework achieves an optimal global detection accuracy of \textbf{91.14\%}, an attack detection recall of \textbf{98.06\%} (intercepting 15,993 out of 16,310 intrusions), and an ROC-AUC of \textbf{0.9620}. Furthermore, Fed-GNIDS completely neutralizes $20\times$ gradient scale-poisoning attacks where traditional FedAvg collapses, sustaining an ultra-low inference latency of \textbf{48.62\,$\mu$s} per flow ($\approx$\,20,568 flows/sec throughput) on commodity edge processing hardware.
\end{abstract}

\section{Introduction}
Modern enterprise infrastructures face targeted multi-stage intrusion campaigns such as Advanced Persistent Threats (APTs), zero-day reconnaissance probes, and Distributed Denial-of-Service (DDoS) assaults. Standard machine learning classifiers rely heavily on centralized repositories of NetFlow/IPFIX logs, creating critical compliance and privacy vulnerabilities.

While Federated Learning (FL) enables distributed subnets to train intrusion models collaboratively without sharing raw traffic logs, conventional FL implementations face three operational challenges:
\begin{enumerate}
    \item \textbf{Loss of Topological Context:} Independent flow classification models treat packets as isolated vectors, ignoring host-to-host interaction graphs.
    \item \textbf{Vulnerability to Byzantine Attacks:} Compromised edge nodes can execute gradient sign-flip or scale-poisoning attacks, destabilizing the global parameter server.
    \item \textbf{Line-Rate Edge Latency Constraints:} Deep models must process high-volume flow snapshots within sub-millisecond budgets to prevent buffer overflow.
\end{enumerate}

To overcome these constraints, we introduce \textbf{Fed-GNIDS}, an edge-deployable, Byzantine-resilient federated intrusion detection system utilizing a spatial-temporal GATv2-GRU architecture with dual-engine calibration and Adaptive Cosine Similarity defense.

\section{System Architecture}

\subsection{Graph Formulation and GATv2-GRU Backbone}
At discrete time windows $t$, subnet traffic is structured as a dynamic attributed directed multigraph $\mathcal{G}_t = (\mathcal{V}_t, \mathcal{E}_t)$, where nodes $v \in \mathcal{V}_t$ represent IP endpoints and directed edges $e_{ij} \in \mathcal{E}_t$ represent communication flows parameterized by connection attributes (e.g., ports, duration, byte rates).

Spatial features are processed via dynamic multi-head Graph Attention Networks (GATv2), eliminating the static-attention bottleneck of standard GATs:
\begin{equation}
\alpha_{ij} = \frac{\exp\left(\mathbf{a}^T \text{LeakyReLU}\left(\mathbf{W}_v [h_i \,\|\, h_j] + \mathbf{W}_e e_{ij}\right)\right)}{\sum_{k \in \mathcal{N}_i} \exp\left(\mathbf{a}^T \text{LeakyReLU}\left(\mathbf{W}_v [h_i \,\|\, h_k] + \mathbf{W}_e e_{ik}\right)\right)}
\end{equation}
The aggregated spatial node states $h_i^{(t)}$ are subsequently passed to a Gated Recurrent Unit (GRU) to retain long-range temporal state vectors across continuous flow windows.

\subsection{Dual-Engine Decoupled Output Heads}
Fed-GNIDS employs two decoupled output heads:
\begin{itemize}
    \item \textbf{Engine 1 (Supervised Classification Head):} Optimizes Binary Cross-Entropy (BCE) with calibrated thresholding ($\theta$) for high-throughput operational threat interception.
    \item \textbf{Engine 2 (Unsupervised Reconstruction Head):} Optimizes edge attribute Mean Squared Error (MSE) to flag atypical flow structures without requiring intrusion labels.
\end{itemize}

\subsection{Adaptive Cosine Similarity (ACS) Byzantine Defense}
During federated aggregation over $K$ participating edge clients, the server computes directional similarity between each incoming client update $\Delta w_k^{(r)}$ and the median update direction $\mathbf{g}_{\text{med}}^{(r)}$:
\begin{equation}
\mathcal{S}_k = \frac{\Delta w_k^{(r)} \cdot \mathbf{g}_{\text{med}}^{(r)}}{\|\Delta w_k^{(r)}\|_2 \|\mathbf{g}_{\text{med}}^{(r)}\|_2}
\end{equation}
Updates yielding negative cosine alignment or anomalous norm expansion are penalized via adaptive weighting, mitigating gradient-inversion and scaling attacks.

\section{Empirical Evaluation and Discussion}

\subsection{Experimental Setup}
The framework was evaluated on the benchmark UNSW-NB15 dataset partitioned into 96 official sequential graph snapshots (24,000 real test flows; 7,690 benign and 16,310 malicious flows) across non-IID client subnets.

\subsection{Comparative Baseline Performance}
Fed-GNIDS was benchmarked against three representative paradigms:
\begin{enumerate}
    \item \textbf{Centralized Random Forest:} Supervised tabular baseline.
    \item \textbf{Local-Only GATv2-GRU:} An isolated data silo without federated knowledge sharing.
    \item \textbf{Spatial Fed-GCN:} A static federated graph without temporal recurrent state memory.
\end{enumerate}

\subsection{Operational Threshold Calibration and ROC Analysis}
Under local Differential Privacy ($C_{\text{DP}} = 1.0$) and non-IID distributions, uncalibrated logit thresholds ($\theta = 0.50$) introduce a severe recall bottleneck (68.47\%). By applying Youden's J-Index optimization, the operational threshold was calibrated to $\theta = 0.4050$.

\subsection{Computational Footprint and Real-Time Edge Profiling}
To evaluate deployment feasibility on edge gateways, hardware profiling was conducted across all 24,000 benchmark flows on an AMD Ryzen 5 architecture.

The compiled model contains \textbf{68,848 parameters}, requiring only \textbf{268.94\,KB} of memory. Federated updates require only 268.94\,KB per uplink/downlink round (4.20\,MB total over 8 rounds per client). Hardware execution yielded a mean per-flow latency of \textbf{48.62\,$\mu$s} ($P95 = 59.16\,\mu$s), sustaining an operational throughput of \textbf{20,568 flows/second}. This confirms the system can process line-rate traffic on standard edge gateway hardware without buffering.

\section{Conclusion}
This paper presented Fed-GNIDS, an edge-deployable federated graph intrusion framework incorporating GATv2-GRU networks, dual-engine threshold calibration, and Adaptive Cosine Similarity defense. Across 24,000 flows from the authentic UNSW-NB15 benchmark, Fed-GNIDS demonstrated \textbf{91.14\%} detection accuracy, \textbf{98.06\%} recall, and complete resilience against $20\times$ scale-poisoning attacks. Requiring only 268.94\,KB of memory and achieving 48.62\,$\mu$s per-flow latency, the framework offers an effective architecture for high-throughput, privacy-preserving edge intrusion detection.
